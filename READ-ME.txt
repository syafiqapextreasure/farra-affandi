OPEN THE WEBSITE
Open dist/index.html in a browser. All navigation, images and enquiry preparation work from the local files. Copy-message support depends on browser permissions; the WhatsApp link is the fallback.
For a local HTTP preview, run: node server.mjs
Then open http://127.0.0.1:4173

EDIT AND BUILD
Edit page content in build.mjs; styles in dist/styles.css; behaviour in dist/app.js.
Run node build.mjs after editing page content.
Run node check.mjs for internal-link and asset checks.
No dependency installation is required.
The dist folder is the self-contained website for a conventional static web host.
